## Protocolo de revisión de cada enlace

Para cada recurso, registrar en una planilla o en el informe de mantenimiento:

1. URL exacta y URL de destino después de las redirecciones.
2. Fecha y hora de comprobación.
3. Resultado con una cuenta estudiante; si corresponde, resultado sin iniciar sesión.
4. Requerimiento de permisos, suscripción, descarga o software específico.
5. Título, autoría, institución, versión y fecha del material.
6. Correspondencia entre el recurso y la consigna del TP.
7. Accesibilidad básica: texto seleccionable, subtítulos/transcripción, contraste, navegación por teclado y descarga legible.
8. Acción tomada: mantener, actualizar, reemplazar, archivar o retirar.
9. Responsable y próxima fecha de revisión.

## Criterios de decisión

- **Mantener:** el recurso es accesible, pertinente, estable y compatible; debe quedar registrada la fecha de revisión.
- **Actualizar:** el recurso es útil, pero requiere corregir capturas, instrucciones, versión, permisos o bibliografía.
- **Reemplazar:** el enlace está caído, restringido, desactualizado o depende de una plataforma inestable y existe una fuente equivalente.
- **Archivar:** el material tiene valor histórico o sirve para documentar una cohorte anterior, pero no debe aparecer como actividad vigente.
- **Retirar:** el recurso no tiene autoría/licencia verificable, expone información sensible, induce a errores o no puede sostenerse pedagógicamente.
