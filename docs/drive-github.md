# Organización externa

## GitHub Pages

Repositorio de trabajo:

`https://github.com/manwithbarba/juegos_inform-tica`

Página estática prevista con GitHub Pages:

`https://manwithbarba.github.io/juegos_inform-tica/`

El archivo `.github/workflows/pages.yml` deja preparada la publicación automática al subir cambios a `main`. La primera activación puede requerir seleccionar GitHub Actions como fuente en **Settings > Pages**.

El repositorio debe contener sólo código, recursos de demostración y casos ficticios o anonimizados. No publicar credenciales, información de estudiantes ni datos clínicos identificables.

## Google Drive

Usar una carpeta privada para los materiales de autoría y Moodle:

```text
Informática 2026/
├── 01_Juegos_fuente/
├── 02_Paquetes_H5P/
├── 03_Cuestionarios_Moodle/
├── 04_Guias_docentes/
└── 99_Archivo_historico/
```

En Moodle se deben enlazar únicamente los materiales destinados a estudiantes. Los archivos editables, bancos de preguntas, credenciales y copias de trabajo deben permanecer restringidos.
