# Adaptación Moodle de los juegos

Esta carpeta contiene la propuesta de implementación de los nueve juegos del repositorio en Moodle:

- `matriz-actividades.md`: decisión pedagógica y técnica para TP1–TP8 e integrador.
- `guia-configuracion.md`: configuración paso a paso para que Moodle registre finalización, aprobación, intentos y resultados.
- `banco-practica.xml`: banco Moodle XML importable con 18 preguntas ficticias de práctica, dos por juego.

## Orden recomendado

1. Importar `banco-practica.xml` en el banco de preguntas del curso.
2. Crear las actividades principales según la matriz.
3. Configurar finalización y calificación para aprobar antes de habilitar el curso.
4. Añadir H5P como interacción complementaria cuando aporte una dinámica visual o de arrastre.
5. Probar con una cuenta estudiante y verificar el informe de calificaciones y el informe de finalización.

El banco no contiene nombres reales, credenciales, casos clínicos identificables ni datos personales. Las preguntas son de práctica: deben revisarse junto con el equipo docente antes de convertirlas en evaluación formal.
