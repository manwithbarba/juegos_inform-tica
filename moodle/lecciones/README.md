## Convenciones comunes de carga

- **Tipo de actividad:** Lección Moodle, con páginas de pregunta de opción múltiple.
- **Nombre:** conservar el prefijo `PRÁCTICA – LECCIÓN –` para diferenciarla de exámenes y archivos históricos.
- **Calificación máxima:** 10 puntos.
- **Puntaje:** respuesta correcta = el valor indicado; respuesta incorrecta = 0 puntos, sin penalización.
- **Intentos:** 2; método de calificación: calificación más alta.
- **Retroalimentación:** mostrar después de cada respuesta para favorecer el aprendizaje.
- **Finalización:** exigir que la persona vea la actividad, reciba una calificación y alcance la calificación para aprobar.
- **Condición adicional:** activar el final de la Lección y exigir el recorrido completo de sus páginas de pregunta.
- **Datos:** todas las situaciones son ficticias y no contienen credenciales, nombres reales ni datos clínicos identificables.

## Secuencia de acceso

La secuencia global recomendada es:

`Bienvenida → TP1 → TP2 → TP3 → TP4 → TP5 → TP6 → TP7 → TP8 → Integrador`

Para este conjunto:

1. **TP1:** se libera después de ver la bienvenida y las instrucciones generales.
2. **TP3:** se libera cuando `PRÁCTICA – TP2` esté completa y aprobada.
3. **TP5:** se libera cuando `PRÁCTICA – TP4` esté completa y aprobada.
4. **Integrador:** se libera cuando `PRÁCTICA – TP8` esté completa y aprobada y se hayan completado los TPs obligatorios definidos por la cátedra.

En cada caso, configurar la restricción como **Actividad completada y aprobada**. El archivo histórico de exámenes 2024/2025 no debe ser requisito de acceso.
